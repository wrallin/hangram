# Hangram

Лаунчер и хранилище аккаунтов Telegram Desktop для macOS, Windows и Linux. Каждый аккаунт — своя
`tdata`; по клику запускается официальный Telegram Desktop с параметром `-workdir`, то есть как portable.

## Запуск

```bash
npm install
npm run dev        # разработка
npm test           # модульные и интеграционные тесты
npm run dist       # сборка дистрибутива вместе с Telegram Desktop
npm run dist:lite  # то же, но клиент скачивается при первом запуске
```

## Как устроено

```
src/shared      типы и IPC-контракт (единственная связь между процессами)
src/main        главный процесс
  core/         крипто, хранилище ключей (vault), запечатывание tdata, база аккаунтов
  tdata/        чтение и запись формата tdata Telegram Desktop
  mtproto/      вход по номеру / QR / строке сессии (teleproto)
  telegram/     загрузка официального клиента и управление его процессами
  services/     жизненный цикл аккаунтов
  app.ts        composition root: блокировка, разблокировка, смена режима
src/preload     типизированный мост (contextBridge)
src/renderer    интерфейс (React)
native/         помощник на Swift: Touch ID через Secure Enclave, вежливое завершение клиента
```

Renderer работает в песочнице без доступа к Node; все вызовы проходят через один канал и
проверяются схемами zod.

## Добавление аккаунтов

| Способ | Что происходит |
| --- | --- |
| Номер телефона | код → облачный пароль → из полученной сессии собирается `tdata` |
| QR-код | то же, подтверждение с другого устройства |
| Войти в Telegram Desktop | открывается чистый клиент, вход выполняется в нём |
| Импорт tdata | копируется существующая папка (кеш медиа не переносится) |
| Строка сессии | StringSession Telethon / GramJS → `tdata` |

## Защита

- PIN → scrypt (N=2¹⁷) → ключ, которым обёрнут случайный мастер-ключ; от него через HKDF — ключи
  базы аккаунтов и каждой `tdata`. Шифрование — AES-256-GCM.
- `tdata` расшифрована только пока открыт её клиент. При блокировке (вручную, по бездействию, при сне,
  при выходе) клиенты закрываются, всё запечатывается, ключ стирается из памяти.
- Кеш медиа (`tdata/user_data`) не перешифровывается: он уже зашифрован локальным ключом Telegram,
  а тот лежит в запечатанном контейнере.
- Touch ID: мастер-ключ дополнительно шифруется на ключ из Secure Enclave с условием
  `biometryCurrentSet` — расшифровку выполняет сам чип и только после совпадения отпечатка.

Ограничения, о которых стоит знать: короткий цифровой PIN перебирается офлайн, если файлы украдены —
используйте длинный; удалённые с SSD файлы нельзя гарантированно затереть; пока клиент открыт, его
`tdata` лежит на диске в обычном виде.

Данные: `~/Library/Application Support/<имя приложения>/data` (macOS), `%APPDATA%` (Windows),
`~/.config` (Linux).
