# Code of Conduct

This project is a place to work on software. Everyone taking part in issues, pull requests and
discussions is expected to keep it that way.

## Expected

- Be respectful. Criticise code and ideas, not people.
- Assume good faith, and be patient with newcomers and with people writing in a second language.
- Stay on topic.

## Not acceptable

- Harassment, insults, or discrimination of any kind.
- Posting other people's private information, including phone numbers, session data or account
  details.
- Asking for help with taking over accounts that are not yours, spam, or evading Telegram bans.
  Such requests are closed without discussion.

## Enforcement

Maintainers may edit or remove comments, close issues, and block people who ignore these rules.
To report a problem, contact the maintainer privately through their GitHub profile.
